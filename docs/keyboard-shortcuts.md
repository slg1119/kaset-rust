# Keyboard Shortcuts

Use Ctrl in place of ⌘ on Windows. On macOS, Kaset preserves the system
shortcuts ⌘Q, ⌘W, ⌘H, ⌘M, and ⌘,.

| Shortcut | Action |
| -------- | ------ |
| `Space`  | Play / Pause (not while a text field, slider, or keyboard-focused button has focus) |
| `⌘→`     | Next track (not in text fields) |
| `⌘←`     | Previous track (not in text fields) |
| `⌘1`     | Go to Home |
| `⌘F`     | Go to Search and focus the search field |
| `⌘⇧L`    | Toggle the Lyrics panel for the current track |
| `Esc`    | Close an open Lyrics or Queue panel |
| `Esc`, `⌘[` | Return from an album or playlist to Home or Search |

In the search field, `↓`/`↑` move through suggestions, `Return` searches the
highlighted suggestion, and `Esc` closes the suggestions. `Return` with no
highlight searches the typed text. When using a Korean input method, pressing
`Return` to commit Hangul only finishes composition. Press `Return` again to
search.

On a track’s More actions button, `↓` opens the menu at the first action and
`↑` opens it at the last. In the menu, `↑`/`↓` move between actions,
`Home`/`End` jump to the first or last action, and `Esc` closes the menu and
returns focus to More actions. In the queue panel, `Alt+↑`/`Alt+↓` move the
focused upcoming track up or down. `Esc` closes the queue and returns focus to
the Queue button.
